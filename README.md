
# 🍔 Burger House — Smash & Grill

Website responsivo de uma hamburgueria gourmet
fictícia, com cardápio digital e sistema interativo
de pedidos.

## Sobre o projeto

O Burger House foi desenvolvido como projeto
demonstrativo de portfólio profissional.

O objetivo é apresentar uma experiência moderna
de cardápio digital, combinando design responsivo
com funcionalidades interativas em JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- CSS Grid e Flexbox
- DOM API
- LocalStorage
- Intersection Observer API

## Funcionalidades

- Interface responsiva
- Menu mobile interativo
- Cardápio com oito produtos
- Filtros por categorias
- Carrinho de compras
- Controle de quantidades
- Remoção de itens do carrinho
- Cálculo automático do subtotal
- Armazenamento local do carrinho
- Formulário de pedido demonstrativo
- Opções de retirada e entrega
- Geração de mensagem personalizada
- Integração configurável com WhatsApp
- Animações durante a rolagem
- Melhorias de acessibilidade e SEO

## Como executar

1. Clone ou baixe o repositório.
2. Abra a pasta no VS Code.
3. Execute index.html com Live Server.

O projeto utiliza HTML, CSS e JavaScript puro,
sem necessidade de instalar dependências.

## Demonstração online

O link será adicionado após a publicação na Netlify.

## Observações

Este é um projeto fictício de portfólio.

Os produtos, preços e fotografias são ilustrativos.

O sistema prepara uma mensagem de pedido,
mas não realiza pagamentos, não confirma pedidos
e não representa um estabelecimento real.
